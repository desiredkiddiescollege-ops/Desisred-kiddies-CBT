Admin EPIN management

- Generate a single EPIN.
- Generate EPINs in bulk.
- Generate quantities such as 1, 10, 50, 100, 500 or 1,000.
- Generate cryptographically strong unique EPIN codes.
- View generated EPINs in the admin dashboard.
- See each EPIN's status: Unused, Used, Expired, or Disabled.
- Set an expiry date where required.
- Set the maximum number of times an EPIN can be used.
- Disable or reactivate an EPIN.
- View when an EPIN was generated and used.
- Prevent duplicate EPINs.
- Never expose sensitive server/database credentials.

Use the database to persist all EPIN information.

Student Result Checker

Create a clear Check Result page.

A student should be able to enter:

- Examination number / student ID
- EPIN

The system must:

1. Validate the EPIN securely on the server.
2. Check that it exists and is active.
3. Check its expiry and usage limit.
4. Verify the examination number/student ID.
5. Retrieve the correct result from the database.
6. Display the student's result clearly.
7. Record EPIN usage according to its configured usage limit.
8. Prevent unauthorized users from viewing another student's result.
9. Show useful error messages when an EPIN or examination number is invalid.
